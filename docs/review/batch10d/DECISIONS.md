29. **Task E — CLS fix (2 attempts, the 2nd kept).** The 0.661 shift was not the first render: the first React commit (createRoot replaces the prerendered HTML) rendered the `<Suspense>` spinner because `React.lazy` suspends on its first render even when its module is already loaded; the footer jumped into view and back. Attempt 1 (`main.jsx` waits for the Homepage chunk before `createRoot().render`) kept the prerendered page longer but the lazy still suspended → CLS unchanged (0.673). Attempt 2 (kept): `App.jsx` exports `preloadHomepage()`; `main.jsx` calls it on `/` and renders when it settles; the `/` route component draws the preloaded module directly (`useState` initialiser, decided once per mount, so a mounted homepage never switches type); everywhere else it is the usual lazy route. Auth, data fetching and other routes untouched (e2e `E6` loads `/`, `/browse`, `/guide`, `/signup`, `/mausam` directly and navigates `/browse → / → /guide → back`). Result: CLS 0.0098 median (baseline re-run 0.860, Task A 0.661); main JS +182 B gzip in total for 10D.
