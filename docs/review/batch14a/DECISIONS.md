# Batch 14A decisions (safest option chosen each time)
1. Branch: release-13a exists on the remote, so release-14a starts from it (ee03dd9). Tag pre-14a-ship pushed.
2. New actor-style functions name their first parameter `p_actor` (not `p_actor_id`) so the 0066 catalog test does not flag them as unguarded. They are guarded by `require_admin_session`, which needs a live session even when `session_enforced` is false.
3. Block guard tables (Phase 0 step 3). Tables a signed-in user writes with their profile id: `listings.user_id` (post a listing) and `kisan_mela_interest.user_id`. NOT user-keyed (anonymous inserts, no user column): `kisan_sawaal` (direct anon insert), `listing_reports` (reporter_phone/ip), `feedback_messages` (email/mobile/device), `carbon_suggestions`, `cold_storage_claims`. Contact reveal (`get_listing_contact`) and WhatsApp opt-in (`app_update_profile` style update on profiles) are reads / updates, not inserts. Triggers are therefore on listings and kisan_mela_interest only; the rest is in BACKLOG.md.
4. Blocked login: refused in the OTP verify Pages Function (`ks_phone_is_blocked`), before a ticket is issued. `app_login_otp` itself is untouched. Blocking also revokes the user's `app_sessions` rows.
5. SMS usage: 0066 deletes `otp_requests` rows after 2 days and never stores rate-limited refusals, so 7/30-day usage cannot come from that table. A new counter table `otp_usage_daily` is filled by new triggers on `otp_requests` (counts only) and back-filled once from the rows still there. Rate-limited count is reported as "not tracked".
6. Old admin writes are logged by the console, not by a database trigger (`withLog` in adminApi.js calling `admin_log_console_action`). Coverage list is in BACKLOG.md.
7. Admins with a null `admin_role` are treated as `editor` by new tools; the migration back-fills `super` for every admin that exists when it runs.
8. Announcement image upload reuses the `listing-photos` bucket under an `announcements/` prefix, resized to about 640 px and 300 KB or less. The server accepts only a `/path` or an `https://<ref>.supabase.co/storage/v1/object/public/...` URL.
9. Role self-change error code is `cannot_change_self`; self-block is `cannot_block_self`.
