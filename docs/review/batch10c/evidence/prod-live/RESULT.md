## HUMAN-REVIEW items found
1. **Prerendered pages point their preload links at `http://localhost:4178/...`** (23 on `/`, 5 on `/guide/`). The site's security policy blocks them, so each page logs a console error per link and the browser cannot fetch the page's own chunks early. This is **not new**: the previous production deployment `0845c733` has the same 23 links. Likely why `/guide` is slower on production (4.5 s) than on the local build (2.8 s). Fix belongs in `scripts/prerender.mjs` (it serves on port 4178); no code change was allowed in this close run.
2. **Slow-phone targets missed on production**: hub 4.5 s vs 4 s; one 345 ms long task on `/guide/find` vs 300 ms.
3. The Cloudflare Insights beacon script is also blocked by the security policy on every page (pre-existing; harmless console error).

Decision rule result: no blank page, no ErrorBoundary, no 5xx; register demo has no OTP; typed data kept → **no rollback**.
